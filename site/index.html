Duo mode, the default

Two droids. One job each.

R2-D2's beeps are short and wordless, so he takes the cues that happen all the time: a session starting, every prompt you send, a failed tool, a subagent rolling off, the session ending. C-3PO speaks when you should look up: approvals, questions, a finished turn, usage alarms, and anything destructive.

Prefer one voice? agent-starwars droid r2d2 keeps it to beeps, droid c3po lets him talk through everything, and droid both picks either droid at random for every cue.

R2-D2

Session start, prompts, tool failures, subagents, session end.

C-3PO

Approvals, questions, completion, power alarms, errors, compaction.

Destructive-command alarm

We're doomed.

When an approval is for something you cannot take back, the cue changes. Recursive force deletes, force pushes, hard resets, dropped tables, mkfs, and dd get "We're doomed.", "This is madness!", or R2's scream instead of the ordinary approval line.

The alarm is a louder cue, not a safety check. It never blocks or approves anything, and the command is never stored or logged; only a yes/no flag leaves the hook.

agent wants to run:
$ git push --force origin main
allow? [y/n]

Usage alarms

This looks very bad.

Claude Code reports why a turn failed. Rate limits, billing errors, and accounts on hold play out_of_power. A reply cut off by the output token limit plays transmission_cut, a C-3PO line that stops mid-sentence. Add the power meter to your status line for a warning before the cell runs dry.

~/project main⚡ 18% power (5h) low
  1. rate_limit · billing_error · account_on_holdout_of_power
  2. max_output_tokenstransmission_cut
  3. status line ≥ 80%power_low

Install

Two commands. I believe this is where I come in.

Run these in your terminal. Sounds need Node.js 22+ and a local audio player; restart your agent afterward.

Claude Code

claude plugin marketplace add mitchtech/agent-starwars
claude plugin install starwars@agent-starwars

Codex

codex plugin marketplace add mitchtech/agent-starwars
codex plugin add starwars@agent-starwars

Gemini CLI

gemini extensions install https://github.com/mitchtech/agent-starwars

Review and trust the sound hooks in Codex's hook settings. Running Agent Navi, Agent Johnny 5, or Agent Warcraft too? Enable one per host so a fairy, a robot, a peon, and two droids do not talk over each other. Full install notes

Sound controls
agent-starwars status
agent-starwars droid c3po
agent-starwars mute prompt_submitted
agent-starwars unmute subagent_started
agent-starwars preset attention
agent-starwars unmute all

Or ask your agent to "switch to C-3PO" or "mute the droids" through the bundled starwars-control skill.
